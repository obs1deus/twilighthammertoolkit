# Addon catalog sources

Discover lists additional addons from a snapshot of [OctoLauncher addons-sources.ts](https://octowow.st/git/OctoWoW/OctoLauncher/src/branch/main/server/src/addons-sources.ts), retrieved November 18, 2026. Descriptions are supplemented by [the resolved catalog](https://octowow.st/api/addons.json). The list is bundled; opening the catalog does not fetch every repository. Only installed components are checked for updates.

Recommended addons remain in their own tab and are excluded from Discover. Recommendations win when names, addon folders or repository identities overlap. In particular, _LazyPig uses obs1deus/_lazypig_updated, BigWigs uses prodigeomix/BigWigs, and Aux uses OldManAlpha/aux-addon. Imported entries retain their configured branch. Categories are assigned locally. Third-party addons retain their own licenses.
