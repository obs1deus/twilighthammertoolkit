# Twilight Hammer Toolkit Roadmap

- [ ] Redesign the Twilight Hammer Sync panel so the installed mode and available actions are easy to see.

- [ ] Rework the remove controls and confirmation. Keep recommended add-ons in the catalog after uninstalling, and remove Git-managed add-ons from Installed Addons after uninstalling them.

- [ ] Add more WoW client modernization options.
- [ ] Add a Launch OctoWoW button that uses the game folder selected in Settings.

## Visual & Audio Mods

- [ ] Add support for managing visual and audio mods, including installed status, enable and disable controls, and restoring original files.
